# Yungang Hu — Portfolio

English-language portfolio for Yungang (Tony) Hu, covering product work, data analysis, and practical AI projects.

Live site: [tony-workbench.github.io](https://tony-workbench.github.io/)

The site is static and dependency-free. Its text, images, and navigation work without JavaScript.

## Pages

- `index.html` — current product work, selected projects, background, and contact.
- `cropcall.html` — CropCall AI hackathon project.
- `slim.html` — SLiM model-compression replication study.
- `vision.html` — chess-piece detection and error analysis.
- `404.html` — missing-page return path.

`styles.css` provides the shared light-gray, ink, and orange visual system. Project claims distinguish team work, prototypes, measured results, and limitations; private company and recruiting materials are not included.

## Local preview

Run `python3 -m http.server 8000` in this directory, then open `http://localhost:8000/`.
