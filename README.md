# Yungang Hu — Portfolio

Personal portfolio of product work, data analysis and practical AI projects, live at [tony-workbench.github.io](https://tony-workbench.github.io/).

## What you need

- Python 3

## Preview locally

1. Get the code:

   ```sh
   git clone https://github.com/tony-workbench/tony-workbench.github.io.git
   cd tony-workbench.github.io
   ```

2. Start a local web server:

   ```sh
   python3 -m http.server 8000
   ```

3. Open <http://localhost:8000/>.
